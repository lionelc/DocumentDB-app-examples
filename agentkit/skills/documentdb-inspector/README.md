# documentdb-inspector

Health-check and diagnostic skill for DocumentDB local Docker containers.

## Overview

This skill provides an automated inspector that runs 6 health checks against a DocumentDB local container and reports results with actionable error codes and fix suggestions. It is designed to **expose issues** rather than fix them.

## Installation

### Claude Code
```bash
cp -r skills/documentdb-inspector ~/.claude/skills/
```

### GitHub Copilot / VS Code
```bash
cp -r skills/documentdb-inspector ~/.copilot/skills/
```

## File Layout

```
documentdb-inspector/
├── SKILL.md                    # Skill entry point (agent reads this first)
├── AGENTS.md                   # Compiled rules (generated by npm run build)
├── README.md                   # This file
├── metadata.json               # Version and metadata
├── documentdb-inspector.sh     # Inspector tool (executable)
└── rules/                      # Individual diagnostic rules
    ├── check-docker-available.md
    ├── check-image-pulled.md
    ├── check-container-started.md
    ├── check-port-reachable.md
    ├── check-tls-handshake.md
    ├── check-crud-smoke-test.md
    ├── setup-from-scratch.md
    └── setup-load-sample-data.md
```

## Prerequisites

| Tool | Purpose |
|------|---------|
| Docker | Container runtime |
| mongosh | MongoDB shell for CRUD tests |
| openssl | TLS handshake verification |
| Python 3 | JSON report generation |

## Quick Start

```bash
# Pull and start DocumentDB
docker pull ghcr.io/documentdb/documentdb/documentdb-local:latest
docker run -dt -p 10260:10260 --name my-docdb \
  ghcr.io/documentdb/documentdb/documentdb-local:latest \
  --username docdbadmin --password MyPass123

# Run the inspector
./documentdb-inspector.sh --password MyPass123 --port 10260 \
  --container my-docdb --tls required
```

## How Compilation Works

Individual rule files in `rules/` are compiled into `AGENTS.md` by running:

```bash
npm run build    # or: node scripts/compile.js
```

The compiled document includes a table of contents and the full content of every rule, organized by category.

## DocumentDB Connection Details

| Property | Value |
|----------|-------|
| Default port | `10260` |
| TLS | Enabled by default (self-signed) |
| Auth mechanism | SCRAM-SHA-256 |
| Connection string | `mongodb://user:pass@localhost:10260/?tls=true&tlsAllowInvalidCertificates=true` |
| Docker image | `ghcr.io/documentdb/documentdb/documentdb-local:latest` |
